# משחק הגרביים

הקרב על השכונה: צבא הנעליים המסריחות פלש לשכונה וחטף את כל הגרביים הבודדות.
הגרביים יורות בועות סבון, מצילות גרביים חטופות ומביסות שלושה בוסים.

- לשחק: https://elazarcules.github.io/Games/sock-game/
- להתקנה כאפליקציה: בתפריט הראשי לוחצים "התקנה כאפליקציה".
  - באייפד ובאייפון: נפתח מסך הוראות (שיתוף ← "הוסף למסך הבית" ← "הוסף").
  - באנדרואיד ובכרום/אדג' במחשב: נפתח חלון ההתקנה של הדפדפן.
- מהאייקון המשחק נפתח במסך מלא, לאורך, ועובד גם בלי אינטרנט (`sw.js`).
- בטלפון ובטאבלט המשחק תמיד לאורך: כשמסובבים לרוחב הוא עוצר ומבקש לסובב בחזרה.
  בדפדפן (לא מותקן) לחיצה על "יאללה, לשחק!" מעבירה למסך מלא, איפה שהדפדפן מאפשר.
- שליטה: גוררים אצבע כדי לזוז, הבועות יוצאות לבד, כפתור "קצף!" מנקה את המסך. במקלדת: חיצים, רווח ל"קצף", P להפסקה.

אחרי שינוי בקבצים כדאי להעלות את `CACHE` ב־`sw.js` (למשל `sock-game-v2`), כדי שהאפליקציה המותקנת תתעדכן.
